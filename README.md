# أسبوع التصميم في السويداء — Hub Design Week

موقع مرجعي عام باللغة العربية، مبني بـ HTML/CSS/JavaScript فقط، ومهيأ للنشر على GitHub Pages.

## مبادئ هذه النسخة

- **Mobile-first:** يبدأ تنسيق الواجهة من عرض الهاتف ثم يتوسع إلى الأجهزة اللوحية والحواسيب، مع قائمة لمس وأزرار قابلة للوصول.
- **رسومات SVG أصلية فقط:** لا صور فوتوغرافية، ولا صور مدفوعة، ولا روابط لمكتبات صور. الملفات السبعة في `assets/illustrations/`.
- **محتوى علني دقيق:** المواعيد والأنشطة مقترحة وليست مؤكدة، ولا تُعرض أسماء مشاركين أو شركاء غير معتمدين.
- **الخصوصية:** لا يوجد جمع بيانات، أو تتبع، أو تسجيل طلبات حالياً.
- **قابل للتطوير:** ست فئات مشاركة، ويمكن تفعيل روابط HTTPS حقيقية لها لاحقاً من ملف إعداد واحد.

## المحتوى

الهوية والرؤية؛ ستة مسارات إبداعية؛ وصف المكان وخيار التوسع المستقبلي؛ برنامج تفاعلي مقترح للفترة 25–29 تشرين الثاني 2026؛ فئات المشاركة؛ القيم والمعايير؛ الأسئلة الشائعة؛ والرؤية المستقبلية لمجتمع التصميم.

## التشغيل المحلي

```bash
python3 -m http.server 8000
```

افتح `http://localhost:8000/`.

## تعديل الموقع

- النصوص والعناوين والأقسام: `index.html`
- التصميم العام: `assets/styles.css`
- ضبط التجاوب من الهاتف أولاً: `assets/mobile-first.css`
- الأيام الخمسة والتفاعل: `assets/main.js`
- تفعيل روابط الطلبات: `assets/site-config.js`
- تغيير الرسومات: `assets/illustrations/*.svg`

### الاستمارات المستقبلية

الموقع ثابت ولا يحتوي Backend. لا تُفعّل `applicationsOpen` إلا بعد تجهيز رابط HTTPS لكل استمارة وفحص إشعار الخصوصية، والتأكد من آلية الوصول إلى الردود. الفئات هي `artist`, `maker`, `workshop`, `space`, `partner`, `crew`. كل فئة تظهر معلومات التحضير الخاصة بها حتى لو كانت الاستمارات معطلة.

## قبل إعلان الرابط للجمهور

راجع لجنة التنسيق الحالية النصوص والحقوق والبرنامج والموعد والاتصالات، ثم أعلن فقط الفقرات المؤكدة. حافظ على فصل مالية هَبّ عن حبق واستقلال حبق ميديا التحريري. لا تُرفع قوائم جهات الاتصال الخاصة إلى مستودع عام.
